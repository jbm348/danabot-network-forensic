DanaBot Network Forensics

Blue Team Malware Investigation

A practical network forensics investigation of DanaBot malware using the CyberDefenders training lab.

Project Details

* Platform: CyberDefenders
* Category: Network Forensics
* Tools: Wireshark, Windows CMD, VirusTotal
* Investigation: Malware traffic analysis

Investigation Objectives

* Identify the attacker’s IP address.
* Identify the initial malicious JavaScript file.
* Calculate SHA-256 file hashes.
* Identify the execution process.
* Investigate the second-stage malicious file.
* Examine threat intelligence findings.
